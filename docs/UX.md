## UX & product rules (current)

### Tabs (what each is for)

- **Home**: one trusted total + category breakdown + recent
- **Scan**: add receipts (camera/upload) + open Library
- **Insights**: spending highlights (VERIFIED-only)
- **Assistant**: ask about spending + basket list + data-backed shortcuts (VERIFIED-only)
- **Shared**: groups + household

### Trust rules users must feel (and UI must communicate)

- **Verified totals only**: spending totals and charts never include `NEEDS_REVIEW`.
- **No silent exclusion**: when there are pending receipts, show a clear CTA to review.
- **Household clarity**:
  - Personal totals = your personal verified receipts
  - Household totals (Shared tab) = household-visible verified receipts

### Copy conventions

- Prefer plain language: “Needs review” / “Not included yet” / “Approve to include”
- Avoid developer terms (“status gating”, “pipeline”, “confidence”)
